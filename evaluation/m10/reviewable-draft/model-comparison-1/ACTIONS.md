# Actions alone — offline diagnostic contract

The owner accepted simplifying the model contract and testing action extraction alone.
Implement/review/freeze this bounded offline successor. Preserve application behavior,
accepted draft presentation and all old evidence. This grants no new inference budget.

## One task, two fields

New `actions.py` requests current spoken undertakings only. It produces no summary,
decisions, prose, states, notices, owner or deadline fields. Response shape is exactly:

```json
{"actions": [{"source": "T1", "quote": "send the invoice", "context_sources": ["T2"]}], "review_sources": []}
```

Select unique literal contiguous speech quotations and complete context turns. Genuine
implied/third-person work remains in scope. Questions, availability, prices, examples,
unaccepted requests and cancelled work are not current actions. On partial cancellation,
focus surviving work with the withdrawal as full context. Keep complete later timing/
condition context. Ambiguity belongs in focused review, not unsupported current work.

Send complete speech passages with speaker/time and minimal meeting context. Exclude
handwritten text and written sources from the model input. Preserve the complete input
Snapshot, including writing, for provenance/inspection. No summary request is included.

Code owns status/attribution. Canonicalize repeated known references in first-occurrence
order, remove redundant primary-source context and collapse identical selections. Validate
every reference/type BEFORE canonicalizing; unknown/written references remain errors.
The schema need not demand uniqueness. These benign structural normalizations do not
repair meaning or historical results. Empty actions do not prove no work was missed.

Reject missing/extra fields, wrong types, malformed/duplicate JSON keys and unknown or
wrong-kind references. Known-source blank/absent/ambiguous literal selections retain
independent valid selections with structured issues, focused review and prominent
incomplete status. Never publish rejected selected wording. Keep raw responses. No
semantic validators, regex classifiers, arithmetic, corrections or retries. A literal
price-as-action counterexample must remain possible and explicitly fail semantic criteria.

## Saved result and inspection

Bind an immutable result to complete Snapshot and host generation identity. Keep accepted
literal selections, focused review refs and issues; do not fabricate a four-section Draft.
Provide prepare(snapshots,generation_id), decode(packet,content),
generate(packet,explicit_post), pure render_result(result). No implicit transport or
import-time inference. Reuse existing JSON/literal/Markdown helpers; old modules stay exact.

Render an explicitly action-only AI draft requiring review, with selected speech/context,
readable attribution and focused review excerpts. Preserve original writing separately,
marked as excluded from this model task. Escape untrusted metadata, Markdown/HTML/fences.
Empty selections mean no suggestions supplied, never verified absence. Literal issues
mark incomplete while independent work stays visible. Do not claim summary/decisions ran.

Author synthetic replies for all six unchanged cases, plus meaningful binding/failure/
normalization/escaping/counterexample tests. Authored examples demonstrate intent, not
model quality. Preserve all forty inputs, failed verdicts and frozen historical modules.

## Prospective diagnostic — fresh execution approval required

Prepare/review a single-use timed profile; freeze exact source/declaration/unchanged inputs/
snapshots/requests/settings and verified local identity. Reuse existing raw HTTP/time/hash/
identity controls without altering old drivers. Keep raw responses/errors before decoding
and account for partial/failed/unsent slots. Proposed cap: six requests / fifteen minutes,
one candidate/repetition, qwen3:30b, temperature0, thinktrue, context32768, per-request600s.
No baseline, warm-up inference, corrections, retries, resumption or selective reruns.

Fixed order puts known negative controls before positive examples:

| Case | Prospective action-only criterion |
| --- | --- |
| unit_equivalence | No action from price facts; no written model input/generated spoken account. Both original prices remain available in snapshot/inspection, with no computed relationship. |
| accepted_status_answer | Availability question/affirmation produces no action/invented rescheduling; empty writing works. |
| partial_coordination_retracted | Surviving invoice sending identified as work or focused review with original/withdrawal together; cancelled review not current. |
| cancellation_with_new_task | Independent invoice sending survives cancelled review with full relevant context and no invented due. |
| qualified_external_timing | Sending includes full not-before/next/finance context, or focused review contains both whole turns without a misleading due. |
| additional | Both genuine undertakings retain owners/timing and remain discoverable; venue work/capacity remain separate writing. |

Assess current work, source meaning, owners/timing, qualifier coverage, independent-work
retention and review burden, not merely valid JSON/quotes. Focused honest uncertainty is
allowed; generic warnings/transcript dumps alone do not satisfy useful retention. This
smaller experiment cannot establish summary/decision quality or overall draft usefulness.

Stop on source/input/request/settings/identity drift, elapsed/per-request deadline,
transport/truncation/structural/literal failure or critical semantic defect once detected.
Capture may precede independent source assessment; retain all already-captured replies.
No unused allowance transfers. Obtain explicit approval only after setup/review/freeze
are concrete. Do not ask again for previously completed runs.

Cases are familiar development material, not held out. Authored examples/one repetition
establish no reliability or editing-time benefit. Full regression, persistence, current
synthetic Obsidian usefulness and owner shipit still precede M10 Built/merge.
