`freeze(output, identity)` is offline and exclusively creates a new directory. It
requires clean exact committed source, preserved inherited import baselines, its own
early HTTP-helper baseline, and unchanged accepted primitives. Transitive source,
fixtures, tests and declarations, original forty-input bytes and complete selected
snapshot are inventoried. No historical Git object is needed beyond current committed
files, including depth-one CI. Each slot gets a DISTINCT host generation even though
both complete snapshots match. The model receives complete speech, unchanged prompt
and schema; original writing is saved and rendered separately, never injected as a
selection or authored answer. Every packet, generation, request, snapshot, setting,
identity and inventory binding, including the unsent slot, is audited before launch
and at subsequent gates. Failed/existing freezes or results cannot be overwritten.
Symlinks and parent traversal are refused. No old globals, policies, bodies or clocks
are assigned or monkeypatched by the implementation.

`run(output, approval, pin, assess)` is the only API that can perform live exchanges.
Approval is nonblank audit context, not authentication. The isolated helper owns ONLY
the two listed chat hashes; copied accepted transport mechanics are unchanged. Only
127.0.0.1:11434, bodyless GET /api/version and /api/tags, model-only POST /api/show,
and the two pinned POST /api/chat requests are allowed, without redirects or retries.
Fresh exact Ollama0.40.13/model-digest/capabilities/thinking/defaults gates precede and
follow each successful transport. Conservative possibly_sent is saved durably before
launch, including spawn failure. The parent kills/reaps only its isolated child on
failure/interrupt; server-side cancellation is not guaranteed. All validation, model
loading, metadata, generation, Chief review, saves, cleanup and sealing share the same
600-second monotonic deadline. No callback, metadata or storage wait extends it.

The new LOCAL Stream/replay preserves accepted strict UTF-8/NDJSON shapes, identity,
counts, index, unknown-tail and known-prefix timing rules. runtime.Stream is unchanged.
Exactly one terminal done=true at strict EOF is required, with done_reason ONLY stop

unlogged tail, transport failure or client timeout stops all later requests, without
retry or salvage. Raw flushed bytes, chunk timing/index, origin, headers, stdout/stderr,

Raw thinking is machine-only evidence; terminal/report output uses counts/times only.
Character counts are never represented as token counts.

A valid `length` terminal is **CENSORED**, even if its partial content parses as JSON.
It NEVER reaches decoding, rendering or the Chief meaning callback. Save progress,
observed content/thinking and explicit `censored_length`; validate post identity/default
and source gates. For continuation the server MUST supply integer eval_count exactly
4096. Missing counters record length_counter_status=missing, cap_match=null and fail-stop;
differing counters record differs/false and fail-stop. No cap match or counters are
fabricated. Other absent counts remain absent. A matching length terminal may continue
to the next slot within budget. Two censored responses can complete transport capture
while answers and semantic outcomes remain incomplete; length is never a task pass.

ONLY a valid stop terminal reaches unchanged strict work_review.decode and saved-only
render_result. Save bound result.json and work-review.md before the REQUIRED callback
`assess(slot, result, deadline)`. Every render, including empty/final selections, needs
Chief review before any next request. The exact verdict has critical:bool and nonblank
assessment:str, with no other fields. Missing/malformed/late/failed/critical review or
failed review save stops. The accepted scoped SIGALRM callback boundary is reused,
refusing an existing timer or non-main thread and restoring the handler. The trusted
Chief callback must honor its deadline and not suppress the alarm or change timers.

failed accepted references are critical. The Chief must read source meaning: there is
